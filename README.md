# InterOS

InterOS is an operating system that runs in the browser.
I made it for Hack Club's Stardance program (WebOS 1 mission).
It is inspired by the mixture of macos and windows.
Live demo: [InterOS](https://vihaan6119.github.io/InterOS/)

## Features

- a desktop with a menu bar and a live clock
- windows you can drag around by the gray title bar
- traffic lights on every window — the red one closes it
- desktop icons to open each window again
- a settings app that changes the wallpaper (sky / sunset / night)
- my own logo

## How to use

1. open the live link (or `index.html`)
2. click an icon on the left to open its window
3. drag a window by its gray top bar
4. click the red dot to close it
5. open settings and click sky / sunset / night to change the wallpaper

## Tech stack

- HTML
- CSS
- vanilla JavaScript (no frameworks, no libraries)
- hosted on GitHub Pages

## How to run it locally

1. download or clone this repo
2. open `index.html` in your browser

That's it — no server or install needed.
